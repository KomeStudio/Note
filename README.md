# Note — Notepad Web App for Personal & Team Use by Kome Studio

> **Note** is a lightweight notepad web app built by [Kome Studio](https://komestudio.com) for personal note-taking and team collaboration. It runs directly in the browser and uses Firebase for authentication and data storage.

[![Kome Studio](KomE.svg)](https://komestudio.com)

---

## Overview

**Note** is a simple, fast, and browser-based notepad application created by [Kome Studio](https://komestudio.com). It is designed for both personal use and team workflows, allowing users to write, edit, and manage notes without installing any software.

Whether you need a quick personal notepad or a shared workspace for your team, **Kome Studio Note** gives you a clean and reliable way to capture ideas and stay organized.

## Features

| Feature | Description |
|---------|-------------|
| 📝 Web-based notepad | Create, edit, and save notes directly in your browser |

## Quick Start

### Requirements

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for Firebase authentication and storage)

### Installation

```bash
# Clone the repository
git clone https://github.com/KomeStudio/Note.git

# Navigate into the project folder
cd Note

# Open index.html in your browser
# or run a local server:
npx serve .
```

Then visit `http://localhost:3000` (or the port shown by your local server).
